# ⚔️ Хроники Зеро (Chronicles of Zero)
### Бесконечная текстовая фэнтези-RPG на базе Google Gemini

«Хроники Зеро» — это глубокая интерактивная текстовая ролевая игра для Android, в которой в роли ИИ Гейм-Мастера выступают нейросети семейства **Google Gemini**. Каждое прохождение уникально: мир, персонажи, сюжетные развилки и последствия ваших решений генерируются на лету в живом литературном стиле.

---

## 🌟 Ключевые особенности игры

- 🧙‍♂️ **ИИ Гейм-Мастер нового поколения:** Сюжет без скриптовых рельсов — полная свобода действий игрока, умные враги, непредсказуемые повороты судьбы.
- 🌌 **Генератор вселенных:** Создавайте собственные миры или используйте готовые шаблоны («Кольцевые Земли», «Элдория», «Мортхейм: Земли Чёрного Пепла», «Ледяная Бездна Айсттема»). Настраивайте лор, регионы, разумные расы и бестиарий.
- 👑 **Дары Зеро и способности:** Уникальные стартовые силы (воскрешение, пространственные карманы, власть над тенями или светом) и динамическое изучение новых умений по ходу приключения.
- ⏱️ **Реалистичное течение времени:** День и время суток (Утро, День, Вечер, Ночь) рассчитываются Мастером динамически по реальной длительности действий героя.
- 💬 **Многорежимный ввод:**
  - `➤ Обычное действие` (влияние на окружение, бой, исследование)
  - `💬 Прямой диалог с NPC` (беседа с конкретным персонажем без метагейминга)
  - `📢 Обращение к толпе` (реакция окружающих жителей или солдат)
  - `🎭 Вопрос Мастеру (OOC)` (уточнение правил, окружения или исправление сцены)
- 🗜️ **Вечная Память и умное сжатие ходов:** Автоматическое сжатие длинной хроники в ёмкие факты по 7–10 слов, предотвращающее переполнение контекста нейросети.
- 🗺️ **Интерактивная карта мира:** Автоматическое нанесение открытых городов, замков и подземелий на координатную карту.
- 🔑 **Архитектура BYOK (Пул API-ключей):** Бесплатный доступ без подписок — игроки используют личные бесплатные ключи Google Gemini с автоматической ротацией пула при исчерпании минутных лимитов (429 Rate Limit Failover).

---

## 🔑 Как получить бесплатный API-ключ Gemini

1. Откройте официальный портал [Google AI Studio](https://aistudio.google.com/apikey).
2. Авторизуйтесь с помощью любого Google-аккаунта.
3. Нажмите кнопку **«Create API key»**.
4. Скопируйте полученный ключ (начинается с `AIzaSy...`).
5. В главном меню игры откройте **«🔑 Настройка API-ключей»** и вставьте ключ.

> 💡 **Совет:** Вы можете добавить 2–3 ключа из разных Google-аккаунтов. Игра автоматически будет переключаться между ними по кругу, если один из них временно исчерпает бесплатную квоту запросов в минуту.

## 🛠️ Сборка и запуск проекта

Проект разработан на **Kotlin + Jetpack Compose** для Android (Android 8.0+ / API 26+).

### Требования:
- Android Studio Ladybug / Meerkat или новее
- JDK 17+
- Android SDK 35
